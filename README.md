# Shopping Cart Website

Live Demo: https://shopping-cart-artemii.netlify.app/

A simple shopping cart application built with React and React Router.

## Features

- Browse products
- Add items to cart
- Update quantities
- View total price

## Installation

git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
npm run dev

## Build

npm run build
